# 深圳普耐斯机电设备有限公司 - 官方网站

## 项目概述

这是深圳普耐斯机电设备有限公司的现代化官方网站，使用 Next.js 14 和 shadcn/ui 组件库重构，专为钢板切割设备制造商打造。

## 技术栈

### 前端框架
- **Next.js 14** - React框架，使用App Router
- **TypeScript** - 类型安全的JavaScript超集
- **Tailwind CSS** - 实用程序优先的CSS框架
- **shadcn/ui** - 基于Radix UI的高质量React组件库

### 主要依赖
- **React Hook Form** - 表单处理和验证
- **Zod** - TypeScript优先的模式验证
- **Lucide React** - 美观的开源图标库
- **Sonner** - 优雅的Toast通知组件

## 项目特性

### 🎨 现代化设计
- 响应式设计，完美适配桌面和移动设备
- 工业风格的蓝橙配色方案
- 流畅的动画和交互效果
- shadcn/ui组件确保一致的用户体验

### 🚀 性能优化
- Next.js 14 App Router架构
- 代码分割和懒加载
- 优化的图片处理
- 快速的页面加载速度

## 开始使用

### 启动开发服务器
```bash
npm run dev
```

网站将在 http://localhost:3000 启动

### 构建生产版本
```bash
npm run build
```
