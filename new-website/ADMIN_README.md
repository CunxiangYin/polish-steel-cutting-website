# 网站管理后台使用说明

## 概述

这是一个完整的网站内容管理系统，允许管理员通过友好的界面编辑网站的各个部分。

## 功能特性

### ✅ 已完成功能

1. **用户认证系统**
   - 安全登录页面
   - 会话管理
   - 自动登录检查

2. **内容管理**
   - 首页横幅编辑（标题、副标题、描述、统计数据）
   - 产品管理（添加、编辑、删除产品信息）
   - 服务管理（管理服务内容和特点）
   - 公司信息管理（企业介绍、联系方式、社交媒体）
   - 图片管理（上传、分类、描述图片资源）

3. **数据管理**
   - 数据导出（备份所有内容为JSON文件）
   - 数据导入（从备份文件恢复内容）
   - 自动备份机制
   - 数据清理功能

4. **用户体验**
   - 响应式设计（支持移动设备）
   - 操作确认对话框
   - 实时保存状态
   - 友好的错误提示

5. **技术特性**
   - 本地存储持久化
   - 版本控制系统
   - 自动备份管理
   - 优化的保存逻辑

## 使用指南

### 1. 首页内容编辑
- 编辑网站首页的横幅标题和描述
- 管理统计数据显示
- 自定义按钮文字
- 实时预览更改效果

### 2. 产品管理
- 添加新产品信息
- 编辑现有产品（名称、类别、描述、特点、价格）

## 故障排除

### 常见问题

1. **登录失败**
   - 检查用户名和密码是否正确
   - 清除浏览器缓存重试

2. **数据丢失**
   - 检查浏览器是否清除了localStorage
   - 使用备份文件恢复数据

3. **保存失败**
   - 检查浏览器存储空间
   - 尝试刷新页面重试

4. **页面显示异常**
   - 检查浏览器兼容性
   - 尝试硬刷新（Ctrl+F5）

### 数据恢复
如果数据意外丢失：
1. 检查是否有导出的备份文件
2. 使用数据导入功能恢复
3. 检查localStorage中是否有自动备份
