Navigation Crowding Test

This page tests the aggressive navigation fix for different screen sizes.

Target Breakpoints:

1600px+ (Large Desktop): All items visible
1400-1600px (Desktop): Hide tertiary items
1200-1400px (Medium Desktop): Hide secondary & tertiary
1000-1200px (Large Tablet): Only core items
768-1000px (Tablet): Hamburger menu
< 768px (Mobile): Compact hamburger menu

What to Check:

  • Navigation items don't overlap or crowd at any screen size
  • Text remains readable and clickable
  • Hamburger menu appears at correct breakpoint
  • Mobile menu opens/closes properly
  • All interactive elements are accessible
